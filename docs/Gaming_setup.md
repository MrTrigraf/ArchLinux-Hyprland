> MangoHud. Учитывает все конфигурации железа (NVIDIA / AMD / Intel).

<a name="Stage-1"></a>
## Этап 1. Базовая установка (Steam + Proton)

### 1. Обновить систему

```bash
sudo pacman -Syu
```

### 2. Включить репозиторий multilib

Steam и 32-битные библиотеки живут в репозитории `multilib`, который по умолчанию
выключен. Открой `/etc/pacman.conf`:

```bash
sudo vim /etc/pacman.conf
```

Найди эти две строки и **раскомментируй** (убери `#` в начале обеих):

```ini
[multilib]
Include = /etc/pacman.d/mirrorlist
```

Обнови базы пакетов после включения:

```bash
sudo pacman -Syu
```

### 3. Установить 32-битные драйверы под своё железо

64-битный драйвер уже стоит с установки системы. Теперь ставим его 32-битную
пару — **строго под свою видеокарту**. Выбери свой блок.

> ⚠️ **Важно:** при установке `steam` (шаг 4) pacman спросит про провайдер
> `lib32-vulkan-driver` и по умолчанию предложит `lib32-nvidia-utils` (первый в
> списке). Если у тебя **не** NVIDIA — не соглашайся на default, выбери номер
> своего драйвера. Неверный провайдер полностью ломает Vulkan. Если поставить
> 32-битный драйвер заранее (этот шаг), конфликта выбора не возникнет.

<details>
<summary><b>🟢 NVIDIA</b> (проприетарный / open)</summary>

```bash
sudo pacman -S --needed lib32-nvidia-utils
```

- Для NVIDIA **отдельного** `lib32-vulkan-*` пакета нет — 32-битный Vulkan
  входит прямо в `lib32-nvidia-utils`.
- Подходит и для `nvidia-open-dkms`, и для `nvidia-dkms` — 32-битная часть
  общая.

</details>

<details>
<summary><b>🔴 AMD</b></summary>

```bash
sudo pacman -S --needed lib32-mesa lib32-vulkan-radeon
```

- `lib32-mesa` — 32-битный OpenGL.
- `lib32-vulkan-radeon` — 32-битный Vulkan для Radeon.

</details>

<details>
<summary><b>🔵 Intel iGPU</b></summary>

```bash
sudo pacman -S --needed lib32-mesa lib32-vulkan-intel
```

- `lib32-mesa` — 32-битный OpenGL.
- `lib32-vulkan-intel` — 32-битный Vulkan для Intel.

</details>

### 4. Установить Steam и игровые утилиты

```bash
sudo pacman -S --needed steam gamemode lib32-gamemode
```

- `steam` — сам клиент (официальный пакет из multilib).
- `gamemode` / `lib32-gamemode` — демон оптимизации на время игры (CPU-governor,
  приоритеты). Многие игры и Proton активируют его сами.

> Если pacman спросит про `lib32-vulkan-driver` и ты **не** ставил драйвер на
> шаге 3 — выбери номер пакета под своё железо (NVIDIA → `lib32-nvidia-utils`,
> AMD → `lib32-vulkan-radeon`, Intel → `lib32-vulkan-intel`), **не** оставляй
> default вслепую.

### 5. Проверить, что Vulkan работает

```bash
vulkaninfo --summary
```

Если команды нет — поставь `vulkan-tools`. В выводе должен фигурировать твой
GPU (GeForce / Radeon / Intel), а не только программный `llvmpipe`. Это
подтверждает, что драйвер и Vulkan подхватились.

### 6. Включить Steam Play (Proton)

Запусти Steam, войди в аккаунт, затем:

**Steam → Настройки → Compatibility (Совместимость):**
- включи **Enable Steam Play for supported titles** — Proton для игр,
  официально прошедших проверку Valve;
- включи **Enable Steam Play for all other titles** — Proton для всех остальных
  Windows-игр (нужно для большинства не-верифицированных тайтлов);
- в выпадающем списке выбери последнюю доступную версию **Proton**.

Готово — можно устанавливать Windows-игры из библиотеки. Они будут запускаться
через Proton автоматически.

### 7. Выбор версии Proton под конкретную игру (по необходимости)

Не каждая игра одинаково работает на одной и той же версии Proton. Если игра не
запускается на дефолтной:

**Библиотека → правый клик по игре → Свойства → Совместимость →** поставь галочку
**Force the use of a specific Steam Play compatibility tool** и выбери другую
версию Proton. Полезно смотреть отчёты совместимости на ProtonDB.

> 💡 **Proton-GE** (кастомная сборка от GloriousEggroll с дополнительными
> фиксами) ставится в Этапе 2 и тоже появляется в этом списке. Для многих игр
> штатного Proton достаточно, но Proton-GE часто чинит проблемные тайтлы.

<a name="Stage-2"></a>
## Этап 2. Lutris + Heroic

Lutris и Heroic позволяют запускать сторонние лаунчеры и игры вне Steam: Lutris —
для GOG, Battle.net, Ubisoft и отдельных установщиков; Heroic — для Epic Games
Store, GOG и Amazon.

### 1. Установить Wine и его зависимости

Lutris умеет качать сборки Wine сам, но официальная рекомендация — поставить
базовый Wine из репозитория, чтобы в системе были все его зависимости.
`wine-staging` — версия с дополнительными патчами, предпочтительна для гейминга:

```bash
sudo pacman -S --needed wine-staging
```

> 💡 **NTSync.** В актуальных Arch-пакетах Wine (`wine`/`wine-staging`) модуль
> ядра NTSync (ускорение синхронизации потоков — заметно помогает в играх)
> загружается автоматически, если поддерживается ядром. Проверить, что он
> работает во время игры: `lsof /dev/ntsync`. Если модуль не грузится сам, можно
> поставить `ntsync-autoload` — но обычно это не требуется.

### 2. Установить дополнительные зависимости для DXVK/VKD3D

Lutris обычно ставит DXVK (Direct3D → Vulkan) и VKD3D (DirectX 12 → Vulkan) сам
под каждую игру. Но 32-битный Vulkan-стек в системе быть должен — он у тебя уже
есть из Этапа 1 (шаг 3). Дополнительно ничего ставить не нужно, если Этап 1
пройден.

> Если конкретная игра пожалуется на отсутствие DXVK/VKD3D — их бинарные версии
> ставятся системно пакетами `dxvk-bin` и `vkd3d-proton-bin` (из AUR). Но это
> резервный вариант — по умолчанию Lutris управляет ими сам.

### 3. Установить Lutris

Lutris есть в официальном репозитории:

```bash
sudo pacman -S --needed lutris
```

Запусти его из меню приложений или командой `lutris`.

### 4. Установить Heroic (для Epic / GOG / Amazon)

Heroic на Arch есть **только в AUR** — официального пакета в репозиториях нет,
`pacman -S heroic-games-launcher` не сработает. Ставим бинарную версию (это
единственный официально поддерживаемый AUR-пакет) через yay:

```bash
yay -S heroic-games-launcher-bin
```

### 5. Настроить Lutris

**a) Проверить runner'ы.** Открой Lutris → **Preferences → Runners**. Wine должен
быть доступен. Через **Manage versions** можно скачать нужные сборки (в том числе
GE-Proton), но для старта достаточно дефолтных — Lutris подтянет нужное при
установке первой игры.

**b) Директория игр.** В **Preferences → Game directories** можно указать, куда
ставить игры. Если у тебя отдельный игровой диск — пропиши сюда путь к нему.

**c) Установка игры.** Игры ставятся по установочным скриптам: в поиске Lutris
находишь игру → выбираешь установочный скрипт → следуешь диалогам. Для сторов
(GOG, Battle.net, Ubisoft) вход происходит через встроенное окно с официальной
страницей логина, включая 2FA.

### 6. Настроить Heroic и войти в Epic

**a) Первый запуск — установить runtime.** Свежий Heroic **не имеет** Proton/Wine
по умолчанию. Это самая частая причина «игра падает при запуске» — пропущенный
шаг с runtime. Открой **Wine Manager** (в левой панели) и скачай последнюю сборку
**GE-Proton** — она будет компатибилити-слоем по умолчанию.

**b) Вход в Epic.** Перейди в раздел **Epic** (или GOG / Amazon) → войди через
официальную страницу логина Epic в открывшемся окне (включая 2FA). После входа
твоя библиотека Epic появится в Heroic.

**c) Установка и запуск.** Выбираешь игру → устанавливаешь → Heroic запускает её
через GE-Proton/umu. Всё управление совместимостью — внутри Heroic, вручную
ничего симлинковать не нужно.

> ⚠️ **Античит.** Игры с kernel-level античитом (многие сетевые тайтлы) обычно
> **не запускаются** через Heroic/Wine/Proton независимо от выбранного runtime —
> это ограничение самого античита, не Heroic. Проверяй статус игры на areweanticheatyet.com.

<a name="Stage-3"></a>
## Этап 3. MangoHud (оверлей мониторинга)

MangoHud — оверлей поверх игры, показывающий FPS, загрузку и температуры CPU/GPU,
частоты, потребление памяти, график фреймтайма и др.

### 1. Установить MangoHud

```bash
sudo pacman -S --needed mangohud lib32-mangohud
```

- `mangohud` — 64-битная версия; `lib32-mangohud` — для 32-битных игр
  (нужна, чтобы оверлей работал и в старых/32-битных тайтлах).

### 2. Как запускать MangoHud

MangoHud не активируется сам — его надо «прицепить» к запуску игры:

- **Steam:** правый клик по игре → **Свойства** → в поле **Параметры запуска**
  впиши:
  ```
  mangohud %command%
  ```
- **Lutris:** в настройках игры (или глобально) включи тумблер **MangoHud**, либо
  добавь `mangohud` в **Command prefix**.
- **Heroic:** в настройках игры есть отдельный тумблер MangoHud.
- **Вручную из терминала:**
  ```bash
  mangohud <команда-запуска-игры>
  ```
  Для OpenGL-игр, если оверлей не появляется, добавь `--dlsym`:
  `mangohud --dlsym <команда>`.

### 3. Где лежит конфиг

Основной файл конфигурации:

```
~/.config/MangoHud/MangoHud.conf
```

Создай папку и файл, если их нет:

```bash
mkdir -p ~/.config/MangoHud
vim ~/.config/MangoHud/MangoHud.conf
```

> Можно задавать конфиг и для отдельных игр: файл
> `~/.config/MangoHud/<имя-исполняемого-файла>.conf` переопределит общий для
> конкретной игры.

### 4. Горячие клавиши (по умолчанию)

- **Показать/скрыть оверлей:** `Shift_R + F12`
- **Перезагрузить конфиг** (без перезапуска игры): `Shift_L + F4`
- **Начать/остановить логирование:** `Shift_L + F2`

Клавиши переназначаются параметрами `toggle_hud=`, `reload_cfg=`,
`toggle_logging=`.

### 5. Что MangoHud умеет выводить (основные параметры)

Параметры включаются построчно в `MangoHud.conf`. `параметр=0` выключает
on/off-параметр.

**Производительность:**
- `fps` — счётчик FPS; `frametime` — время кадра (мс); `frame_timing` — график
  фреймтайма (наглядно показывает микрофризы).
- `fps_limit=0,60,144` — ограничение FPS (переключается по кругу); `0` — без
  лимита.
- `vsync=` / `gl_vsync=` — управление вертикальной синхронизацией.

**CPU:**
- `cpu_stats` — загрузка CPU; `cpu_temp` — температура; `cpu_power` —
  энергопотребление; `cpu_mhz` — частота; `core_load` — загрузка по ядрам.

**GPU:**
- `gpu_stats` — загрузка GPU; `gpu_temp` — температура; `gpu_core_clock` —
  частота ядра; `gpu_mem_clock` — частота памяти; `gpu_power` — потребление;
  `vram` — использование видеопамяти.
- `gpu_junction_temp` — температура «горячей точки» (актуально для мониторинга
  на нагруженных картах).

**Память и система:**
- `ram` — использование ОЗУ; `swap` — подкачка; `procmem` — память процесса.
- `resolution` — текущее разрешение; `time` — системное время;
  `gpu_name` / `cpu_name` — модели железа; `vulkan_driver` — версия драйвера.

**Внешний вид:**
- `position=top-left` (или `top-right`, `bottom-left`, `bottom-right`) —
  положение; `font_size=24` — размер шрифта; `alpha=0.5` — прозрачность фона;
  `background_alpha=0.4` — прозрачность подложки.
- `full` — включить почти все параметры разом; `fps_only` — показывать только
  FPS (минимальный режим).

### 6. Рабочий конфиг под твою систему

Ниже — сбалансированный конфиг: информативный, но не загромождающий экран.
Скопируй в `~/.config/MangoHud/MangoHud.conf`.

```ini
### Положение и внешний вид
position=top-left
font_size=22
background_alpha=0.4
round_corners=8

### FPS и фреймтайм
fps
frametime
frame_timing
fps_limit=0

### CPU
cpu_stats
cpu_temp
cpu_mhz
cpu_power

### GPU (работает и для NVIDIA, и для Intel — параметры одни)
gpu_stats
gpu_temp
gpu_core_clock
gpu_mem_clock
gpu_power
vram

### Память
ram

### Служебное
gpu_name
resolution
vulkan_driver
```

> 💡 Один и тот же конфиг работает на обеих машинах. На Intel-ноуте часть метрик
> (например, `gpu_power`) может не отображаться, если драйвер не отдаёт эти
> сенсоры — это нормально, MangoHud просто пропустит недоступное. На
> NVIDIA-десктопе доступны все перечисленные параметры.

### 7. Логирование и бенчмарки (опционально)

MangoHud умеет писать логи фреймтайма для анализа производительности. Добавь в
конфиг папку вывода:

```ini
output_folder=/home/<имя>/mangohud-logs
```

Логирование включается на лету клавишей `Shift_L + F2`. Полученные логи можно
визуализировать (график фреймтайма, 1%-low, средний FPS) локально или загрузив
на FlightlessMango.com.
